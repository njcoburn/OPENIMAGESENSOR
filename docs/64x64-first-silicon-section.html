Current device layout — exact implemented geometry

This is the actual 64-column readout bank joined to one row of 64 pixels, rendered from the same GDS used for the completed alternating/inverse electrical matrix. Its overall size is 2,667.87 × 1,069.80 µm (2.668 × 1.070 mm). The tall repeated rectangles are storage capacitors; the light-sensitive pixels form the small row along the bottom.

Reading the layout

  1. Pixel row: 64 photodiodes at 40 µm pitch, each with an 18 × 18 µm clear optical aperture.
  2. Analog circuitry: per-column capture, storage switching and selected readout.
  3. Storage: eight MIM capacitor plates per column, 512 plates across the bank.
  4. Ground return: three wide M4 rails along the top and left, with M5 returns from the columns.
  5. Reference: the shared reference MOS pair sits to the left of column zero.
  6. Shared buses: supply, bias/reference, capture controls and buffered output run above the pixels.

The extracted census is 642 MOS devices, 512 MIM plates and 64 diodes. Main Magic/KLayout DRC reports zero errors; direct and resistor-collapsed LVS pass. These are scoped development checks.

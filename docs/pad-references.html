The 3.3 V and ESD questions

The original library operating table specifies 4.5–5.5 V I/O supply. Our core uses 3.3 V thin-oxide devices. The template source ties core and I/O supplies together for the foundry library; it selects separate domains for the OCD option. We must resolve the voltage domains before copying a wrapper.

The foundry analog-pad documentation describes a thick-gate application and HBM protection diodes, and requires secondary protection near the internal devices. It specifies a CDM diode perimeter above 25 µm and a poly resistor above 50 Ω. These are starting requirements, not proof that a particular network protects our thin-oxide circuit. HBM and CDM are different electrostatic-discharge test models.

What is already installed

Read-only inspection of the running tools container confirmed /foss/pdks/gf180mcuD/libs.ref/gf180mcu_fd_io contains GDS, LEF, CDL, SPICE, Magic, Verilog, Liberty and Xschem views. The installed analog SPICE cell has signal-to-supply protection diodes using 6 V diode models. The OCD library directory is absent. No PDK installation was changed.

Proposed interface and next checks

  • Four analog connections: BUF (ADC output), BIAS, PREF and VRESET. Nine digital inputs: RST0–2, ROW0–2 and SEL0–2. Add the required supply/ground pads and any optional debug pads. Internal COL0–2 and OUT need not all be bonded out.
  • First simulate one analog-pad/protection candidate at the actual BIAS, PREF, BUF and VRESET voltages, over process, temperature and supply. Replace the assumed 5 pF pin load with characterized/model-derived capacitance; check leakage, output settling and power sequencing.
  • Proposed BIAS leakage budget: 1% of 0.5 µA is 5 nA. This is a design target, not a published pad specification. The reviewed references do not establish that this target is met over temperature.
  • Then pin the source revisions, import matching layout/netlist views, connect protection rails, and run pad-inclusive LVS, DRC and extracted simulations. Confirm wire-bond geometry and optical access with the chosen assembly process.

Custom option: arranging standard cells into our own ring is reasonable. Designing a new bondpad and ESD network is a separate characterization task; DRC/LVS alone cannot establish ESD robustness. Keep the pixel array clear of bond wires and opaque packaging.
